# PCR Simulator 🧬
An interactive, clickable PCR simulation built with pure HTML + SVG, designed for biology learning.

🔗 **Online Demo**: https://Iriiii1201.github.io/pcr-simulator/

## 🎮 Features
- ✅ Click to add PCR reagents; the run button stays locked until all components are ready
- ✅ Hover & click DNA / primer molecules on the canvas to pop up explanations
- ✅ Adjustable temperature slider. Reaction only proceeds when temperature matches the required stage
- ✅ Built-in term tooltip `?` for quick definition lookup
- ✅ Animation, cycle counter, DNA molecule count, auto-play & reset function
- ✅ No installation needed, works directly in browser

## 🧪 What you need for a PCR mix
1. Template DNA
2. Forward & Reverse Primers
3. Taq DNA Polymerase
4. dNTPs
5. Reaction Buffer

## 📖 How to play
1. Add all required reagents first
2. Drag the temperature slider to hit the target temperature for each step
3. Click `Next Step` to advance, or use `Auto Play`
4. Click molecules and question marks to read explanations
5. Press `Reset` to restart the whole PCR cycle

## 📚 Learning Focus
Visualize the 3 core steps of PCR in each cycle:
- Denaturation (~94℃)
- Annealing (~55℃)
- Extension (~72℃)

> This simulator is made for AP Biology / molecular biology self-study and classroom demonstration.
